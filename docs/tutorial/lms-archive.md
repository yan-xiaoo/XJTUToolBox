# 所选活动归档

在思源学堂页面选择需要的活动，打开原有“批量下载”对话框，勾选“归档到独立文件夹并生成清单（含校验值）”。归档仍使用原来的账户会话、LMS API、附件收集逻辑及下载线程。

每次归档会在所选目录下创建独立的 `LMS归档_…` 文件夹。可继续选择统一存放或按活动存放；本次任务内的同名文件会使用不同文件名，避免互相覆盖。

目录中的 `manifest.json` 记录：

- 课程名称、所选活动及归档时间。
- 文件相对路径、完成状态，以及成功文件的大小和 SHA-256 校验值。
- 获取活动详情、批阅附件失败，以及附件缺少下载地址或数据格式异常的记录。
- 整体状态：`complete`、`partial`、`cancelled` 或 `failed`。意外退出前未结束的任务可能保留 `running` 状态，不能视为归档完成。

清单不保存账户凭据、下载 URL 或其临时签名，但课程及文件名称仍属于个人资料。下载先写临时文件，成功后再替换目标文件；失败或取消不会删除此前已存在的完整目标文件。正在等待网络响应时，取消可能需要等到下一段数据到达或请求超时。期间进度条保留停止状态，不会强制终止负责清理文件和保存清单的协调线程；正常收尾后，清单记为 cancelled。

此功能仅归档当前选中的活动及原有下载器支持的附件和回放，不自动遍历全部课程，不新增直播录制、网页正文导出或断点续传。SHA-256 用于检查本地文件是否改变，不能验证服务器内容的真实性。未勾选归档时继续使用普通批量下载，不生成清单。
