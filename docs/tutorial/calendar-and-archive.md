# 日历订阅与课程资料归档

## 课表日历

在课表页面获取当前学期课表并设置开学日期后，打开“日历设置”。校历中的第 1 周星期一必须与课表一致。默认夏冬作息沿用百宝箱的时间表，可在配置中核对、修改停课日期和调课安排。

- ICS 导出使用本地课表和考试数据，可选择提醒。导出文件与 URL 订阅各自保存更新记录，互不推进对方的发布状态。
- URL 订阅需要安装 Git，并准备自己有写入权限的仓库和专用分支，以及对应的静态托管地址。登记后手动点击发布；后台不会定时上传。
- 发布内容相同会跳过推送。课程显示名、地点变化保留事件身份；考试改期因本地数据库没有上游考试 ID，会撤销旧场次并产生新场次。
- 不完整的考试响应保留此前的场次。若历史记录不足以证明可以安全覆盖，导出、发布和链接轮换会停止，需重新获取完整考试安排或修复记录。明确完整的空列表可以撤销考试。
- 发布超时或结果不明时，先使用“修复发布状态”。更换链接会使旧链接失效，客户端需重新添加。修复、更新和轮换都使用专用后台任务。

订阅地址是访问入口，不是加密保护。公开仓库中的课程、时间、地点和考试内容可能被他人查看。请核对发布提示，不要把真实日历提交到本项目。程序只向日历专用分支写 ICS；远端包含其他文件时拒绝覆盖。

## 思源学堂资料归档

先在思源学堂页面登录并打开课程，再点击“课程资料归档…”。

1. 点击“扫描预览”。扫描读取活动附件、页面正文中的附件和作业/考试活动附件；可勾选录像与回放。扫描失败会在清单中显示，不会当作“没有资料”。
2. 核对并勾选资源，点击“下载所选…”，选择本地目录。附件可按章节整理，录像和回放按活动存放。
3. 完成后查看 `manifest.json` 中的成功、失败和 SHA-256 记录。网络中断可以重新扫描、下载；只有能够核对版本的分片才续传，没有可信版本信息时从头下载。

归档使用当前账户会话的内存副本，不读取独立下载脚本的登录缓存，也不把 Cookie、密码或临时回放链接写进清单。不同账户、课程存入不同子目录。切换账户后，旧归档窗口会失效，正在运行的任务会取消。取消时可能要等待当前网络请求结束。

该入口集成 `XLJFZ/xjtu-siyuanxuetang-grab` 的采集、下载和章节整理核心，保留上游 MIT 许可证。百宝箱原有的批量下载入口继续保留；它不是本次新增功能。新入口仅归档所选课程的资源，不自动遍历全部课程，不接入上游独立浏览器登录、直播录制或说明文档导出命令。重新归档已完成文件会重新取回并计算哈希，不仅凭文件大小认定内容未变化。

## 开发与验证

日历依赖固定为 `xjtu-timetable-calendar==0.11.1`。资料下载核心的固定提交和本地适配记录见 `lms/vendor/siyuan_grab/README.md`。

```shell
uv sync --frozen
uv run python -m test.ci.run_offline_review --domains schedule qt-ui
uv run python build.py
```

离线测试入口隔离配置目录、禁用账户密钥存储并阻止 Python 网络连接；发布测试只使用本地临时 Git 仓库。测试包含合成课表、考试完整性、发布失败恢复、真实子进程退出、界面任务状态和合成 HTTP 响应。它不能代替真实学校接口、WebVPN、手机日历客户端或各平台发行包的人工验收。
