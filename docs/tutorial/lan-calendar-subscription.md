# 局域网日历订阅

在课程表的“更多…”菜单选择“局域网日历订阅”，选择本机的局域网地址和端口，再点击“开启订阅”。将链接添加到能够直接访问该地址的日历客户端。

- 电脑和订阅设备需要在同一可互通的局域网。电脑需保持运行，工具箱不能退出；最小化到托盘不影响订阅。
- 若系统防火墙询问是否允许访问，仅按实际使用场景允许可信的专用网络。工具箱不会修改防火墙、路由器或端口转发设置。
- 地址 `127.0.0.1` 仅供本机使用。校园网、访客网络或路由器的设备隔离可能阻止其他设备连接。
- 服务使用 HTTP。需要公网 HTTPS、由云端代为抓取的日历服务无法直接使用此局域网链接。
- 工具箱生成的是本机已保存的当前学期课表和考试。它不会因此自动登录学校系统或拉取新课表；请在工具箱内刷新学校数据。
- 课表界面刷新时更新订阅内容，开启期间还会每 30 秒检查一次本机数据。日历客户端何时同步取决于其自身刷新机制。
- 切换账户或学期时停止订阅，防止原链接意外读取另一个账户或学期的数据。请在确认新的订阅范围后手动开启。
- “忽略节假日”使用开启时有效的本机缓存。没有缓存时，请先勾选忽略节假日导出一次 ICS。
- 重启工具箱后需要手动开启。同一账户的订阅标识会保存在本机；IP 地址和端口不变时可沿用原链接。地址变化后需要更新客户端中的链接。

订阅链接持有人可以读取课名、上课地点和考试安排。链接中包含随机标识，但 HTTP 不加密传输，请只在可信网络开启，不要公开链接或将端口暴露到互联网。服务限制同时处理的连接数，并会断开超时请求。点击“停止订阅”或退出工具箱时会中断现有连接；停止后，本机不再提供日历内容；客户端此前保存的事件不会因此立即被删除。

文件导出与订阅共用原有的 ICS 生成逻辑，沿用项目已使用的 `icalendar`。局域网服务使用 Python 标准库，不需要 GitHub 仓库、访问令牌或新的业务库。手机客户端的实际兼容性仍需按所用客户端验证。
